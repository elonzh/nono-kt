# Security policy

nono-kt is a client for the nono CLI; it is not itself a sandbox. The caller
owns the sandbox policy, executable trust, environment, and child arguments.

Do not report vulnerabilities in public issues. Use the repository's
[private vulnerability reporting](https://github.com/elonzh/nono-kt/security/advisories/new)
or contact the maintainer through the private address listed in the GitHub
security advisory form.

Include the affected nono-kt and nono versions, operating system, reproduction,
and impact. Supported releases are listed in
[compatibility documentation](docs/compatibility.md).
